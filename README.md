# Jev as an energy landscape

Does Jev (TypeSafe AI's "System One" decision model) carry a Hamiltonian-like landscape, and is that
landscape usable for quantum-chemistry calculations?

- `survey/`: literature survey notes and BibTeX
- `harness/`: Jev API client, probes and caching
- `experiments/`: coupling, precision and quantum-chemistry decision experiments
- `data/`: cached raw API responses (for replay)
- `paper/`: LaTeX source for the arXiv preprint (cs.LG; cross-list physics.chem-ph, quant-ph)
